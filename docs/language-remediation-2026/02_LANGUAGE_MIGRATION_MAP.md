# Antaeus Language Migration Map

## Governing rule

**Antaeus may have a point of view. It may not require translation.**

This map is semantic, not a blind find/replace list. The replacement must reflect what the term means in the specific context.

| Current term | Problem | Preferred language | Rule |
|---|---|---|---|
| `Ground` | private ontology | Workspace map / navigation | Retire from user-facing language. If retained internally, never use it as the only functional name. |
| `Touch the Ground` | private ontology | Open workspace map | CTA must say what opens. |
| `whole motion` | semantic compression | sales workspace / sales process / pipeline + activity | Replace with the exact scope in that context. |
| `motion` | semantic compression | sales process / activity / pipeline / outreach / deal process | Never use as a catch-all. |
| `heat` | private ontology | account priority / signal strength | Name the actual metric; if a score is shown, explain inputs. |
| `hottest` | private ontology | highest-priority account | Use only if literally comparing measured temperature—otherwise retire. |
| `sharp` | private ontology | specific / well-defined / high-quality | For ICP, prefer 'ICP specificity' or 'well-defined ICP'. |
| `sharpness` | private ontology | specificity / quality | Replace with the actual quality being assessed. |
| `bite` | metaphor | match / accounts that fit | Retire in ICP and territory surfaces. |
| `where it bites` | metaphor | matching accounts | Retire. |
| `carve` | metaphor | create / define / segment | Use the literal action. |
| `Live Edge` | private ontology | Activity feed / recent activity | Choose one functional name and use it consistently. |
| `the machine` | personification | automated update / Antaeus automation | Name the process or source. |
| `machine` | personification | system / automation | Avoid as a brand noun. |
| `one move` | semantic compression | highest-priority recommended action | State the action and why it ranks first. |
| `system's pick` | personification | recommended action | Name recommendation + evidence. |
| `workspace is awake` | personification | workspace setup is complete / analysis is ready | Retire. |
| `awake` | personification | ready / active / analyzed | Use actual state. |
| `wake-up` | personification | enrichment complete / data loaded | Internal and external. |
| `first morning` | metaphor | first completed setup / first daily overview | Use time literally. |
| `morning landing` | metaphor | daily overview / welcome | Retire as functional label. |
| `landing` | metaphor | arrival / overview / completion | Use exact event. |
| `dividend` | metaphor | benefit / result / output | Retire from product explanation. |
| `thread` | semantic compression | account/deal history / communication history / stakeholder path | Name which history or relationship is meant. |
| `whole thread` | semantic compression | related account and deal activity | Use literal title. |
| `pressure` | semantic compression | risk / urgency / priority | Choose the actual construct. |
| `pulling` | metaphor | factors increasing priority | Use reasons/factors. |
| `decaying` | metaphor | becoming stale / risk increasing | State the observable change. |
| `dying` | metaphor | high loss risk / likely to be lost | Retire from state labels. |
| `dies` | metaphor | is lost / becomes unlikely to close | Use only in optional editorial copy, not diagnosis. |
| `Future Autopsy` | branded name | Deal Risk (or retain as title + literal subtitle) | Can survive only with explicit functional subtitle. |
| `climb` | metaphor | readiness progression | Retire from functional language. |
| `summit` | metaphor | highest readiness level | Retire. |
| `inheritable` | private ontology | runnable by another seller / independently runnable | Replace with concrete operating independence. |
| `You are the system` | aphorism | Founder-dependent | Replace state name. |
| `Building` | ambiguous state | Partially documented | When used as readiness state. |
| `Inheritable with guardrails` | private ontology | Runnable with founder support | Replace readiness state. |
| `Hire-ready` | ambiguous state | Runnable independently | Replace readiness state. |
| `Hire-ready, repeatable` | ambiguous state | Documented and repeatable | Replace readiness state. |
| `handoff kit` | private ontology | sales handoff documentation | Use standard noun. |
| `seed` | internal metaphor | initialize / enter setup data | Retire from user-facing onboarding language. |
| `seeding` | internal metaphor | onboarding data collection / workspace initialization | Rewrite internal doctrine too. |
| `heavy-seeding` | internal metaphor | comprehensive onboarding | Rewrite internal doctrine. |
| `floor` | semantic compression | minimum requirement | Use only when standard, otherwise state the threshold. |
| `thin` | semantic compression | incomplete / insufficient / limited | Name what is insufficient. |
| `front` | private ontology | negotiation workstream / issue area | Getting to Signed: Legal, Security, Finance, Business approval. |
| `face-off` | metaphor | current blocking issue | Retire. |
| `your line` | metaphor | your proposed position | Retire where it means negotiation position. |
| `relay` | metaphor | introduction / forwarded request | Retire as conceptual model. |
| `carries weight` | idiom | has influence with this account | Prefer literal influence language. |
| `air cover` | metaphor | LinkedIn outreach / supporting outreach | Retire. |
| `run to signature` | metaphor | signature process | Use literal process name. |
| `run-to-signed` | private ontology | signature process | Retire internally. |
| `system saw` | metadiscourse | recent changes / analysis / observations | State the result rather than narrating system perception. |
| `system's read` | metadiscourse | analysis / assessment | Prefer the actual output category. |
| `what the system saw` | metadiscourse | recent changes / analysis | Retire as a section heading. |
| `read` | semantic compression | analysis / assessment / summary | When used as a noun, replace with the specific artifact. |
| `heartbeat` | metaphor | scheduled check / recent activity check | Use literal monitoring language. |
| `standing orders` | metaphor | saved monitoring rules | Retire. |
| `fires` | metaphor | matches / triggers / detects | Use literal event. |
| `the data disagrees` | personification | evidence conflicts with an assumption | Use evidence language. |
| `walk in cold` | idiom | start without preparation | Avoid as core explanatory language. |
| `on the wire` | idiom | scheduled / active / due today | Name actual status. |
