# Antaeus Language Remediation — Index and Phase Status

Branch: `language-remediation-v1`

## Governing target

Reduce the rendered product-language saturation score from **93/100** to **20/100 or below**, using the unchanged nine-dimension rubric documented in `00_MASTER_PLAN_AND_METHODOLOGY.md`.

## Source method

Language decisions are made against the full rendered preview corpus generated by `tools/preview/build-transcript.js` and represented under `preview-transcript/`. Repository source is then traced and changed at the highest correct implementation point. Generated transcript output is never patched as the implementation.

See `01_SOURCE_METHODOLOGY.md`.

## Implementation rule

Do not let a coding agent independently rewrite the product. The language decisions in this directory are the approved semantic source. The coding task is to locate the source that produces the rendered language, implement the approved decision, preserve behavior/data semantics, and validate the regenerated product.
