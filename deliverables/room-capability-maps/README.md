# Room capability maps (2026-07-07)

A comprehensive reference map for every room — *everything the room is supposed to offer*. Built in the same format as the Discovery Studio capability map (which lives with the guardian specs, being the most strictly-specified room). These are the **binding mind contract** the wire-to-production build runs against (`deliverables/plans/antaeus-wire-to-production-plan-2026-07-07.md`): every wired room's Pass-1 (Mind & Capability Fidelity) walks its map line by line.

Each map: 1·Purpose · 2·What it offers (the full capability table) · the room's distinctive structure (movements / verdicts / fronts / segments / streams / lanes / cues, as applicable) · N·Flows (in / out) · N·Guardrails (must-never-be-flatten | what-it-is-NOT). Compiled from canon §4.x + shipped `src/<room>` + reconciled to current doctrine.

Banned-word occurrences are confined to the "Banned on the face" documentation tables (the per-room language teardowns) — reference usage documenting what the *product* may not say, exactly as the Discovery map documents "Proof threshold."
