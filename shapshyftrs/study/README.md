# Source studies

Phase 1 of the v2 brief. One file per source, written from the real material — renders,
CAD, brand PDFs rendered to page images, shipped interfaces, and production captures.

These are the evidence base for hard rule 3 ("fidelity is measured, not remembered").
Every colour, proportion and material in `tokens/` and `materials/` traces back to a
measurement recorded here.

**This directory is never published.** It indexes private codebases and names real asset
files. Only `dist/` is ever published.

| file | source | what it covers |
|---|---|---|
| `puff-junction.md` | PUFF JUNCTION | the grinder, pouch, bottle and lighter; the concrete and brass recipes; the knurl and harlequin geometry; the two-brands problem |
| `darkest-shades.md` | DARKEST SHADES | nine frame models with real dimensions; the angular mark traced and verified; the lens recipes; the studio grammar |
| `digs.md` | DIGS | AC-LST-001 with its full graded spec; the knit and wash; the wordmark and the DD monogram; the three-value palette |
| `aesdr.md` | AESDR | the four visual generations and which one ships; the iris and its reservation rules; Leponeus; the spent registers |
| `antaeus.md` | Antaeus GTM OS | the Grounded-A geometry; the graph-paper field; the two greens; sixteen settled surfaces read from renders |

Assets are cited by filename only throughout. No contractor's name appears in any study.
