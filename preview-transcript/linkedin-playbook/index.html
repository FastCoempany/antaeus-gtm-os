4. What this room is for and how it works

The room's capability map: its purpose, every part and what it does, what flows in from and out to other rooms, and what it must never become.

LinkedIn Playbook · Live Instrument · capability map

LinkedIn as disciplined air cover — never the opening scene.

Live Instrument (live execution) · settled 2026-07-06 (the one move)

Use LinkedIn as disciplined air cover — never the opening scene. Public cue first, ask only when trust has compounded. The inbox is not where you start: the five cues run watch public signal → comment with one operating read → connect after recognition → give-first → ask only when it’s warranted.

Sourced from: canon §4.10 + the motion engine + 5-cue ladder (shipped src/linkedin-playbook). Settled design: linkedin-playbook-one-move-2026-07-06.html.
